# Аэролетопись — интерактивный музей российской авиации

Статический сайт с хроникой, авиапарком, очерками об авиационных центрах, заданиями и аркадной «Авиабитвой». Для сборки и запуска достаточно Python 3.

## Локальный запуск

В корневом каталоге проекта:

```powershell
python build.py
python -m http.server 8000 --bind 127.0.0.1 --directory dist
```

Откройте [Авиабитву](http://127.0.0.1:8000/#battle) или [хронику](http://127.0.0.1:8000/#timeline). Лучший результат игры и открытые карточки сохраняются в браузере для конкретного адреса и порта.

## Исходники и сборка

- `index.html` — разметка, стили и входная точка.
- `site/js/catalog.js` — данные музея. Название, год и тип самолёта в игре берутся из карточки авиапарка.
- `site/js/museum.js` — навигация, карточки, задания и хранение прогресса.
- `site/js/battle.js` — правила аркады, игровые параметры и отрисовка.
- `site/assets/air-battle/` — один комплект PNG для меню, боя и иллюстраций к карточкам.

Сборка копирует исходники и ресурсы в `dist`, сохраняя относительные пути. Новая версия использует распакованные исходники релиза v25. Фрагменты `site/kr-*.b64` и `payload/` сохранены как архив и в сборку не входят.

## Авиабитва

Ил-2 доступен сразу. Для открытия остальных самолётов достаточно просмотреть их карточки через «Авиапарк», хронику или меню выбора. В игру включены 12 боевых моделей. «Русский витязь» представлен в музее как опытный самолёт, По-2 — как учебный и многоцелевой, Ан-2 — как транспортный, АНТ-25 — как рекордный.

Для управления используйте ← / →, A / D, мышь или касание. Огонь автоматический, Esc ставит бой на паузу. Скорость и поперечное ускорение определяют отзывчивость, прочность — число выдерживаемых столкновений. Одиночные и парные залпы имеют разный темп и урон. Танк приносит 10 очков, дрон — 15. Каждые 15 уничтоженных противников начинается новая волна.

Технические характеристики в музейных карточках относятся к реальным самолётам. Параметры меню «Авиабитвы» действуют только в аркаде.
