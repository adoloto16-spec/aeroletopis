# Крылья России — интерактивный музей российской авиации

В репозитории опубликована веб-версия релизного архива **v22**.

Сайт статический и не требует backend-сервера. Фотографии и часть материалов загружаются по HTTPS с внешних источников, как в исходном архиве.

## Публикация

Проект настроен на автоматическую публикацию через GitHub Actions и GitHub Pages при изменениях в ветке `main`.

Адрес сайта:

https://adoloto16-spec.github.io/krylya-rossii/

Если GitHub Pages ещё не активирован для репозитория, в **Settings → Pages → Build and deployment → Source** нужно один раз выбрать **GitHub Actions**.

## Версия v22

- 17 самолётов с фото; SVG не используется как основной визуал карточек.
- 15 важных людей авиации с реальными портретами.
- Миниатюры самолётов в «Хронике» — реальные фото, клик открывает подробную карточку.
- Все 12 событий имеют изображение.
- Раздел «Авиационные центры России» включает исследовательские центры, конструкторские школы и производственные площадки, включая КнААЗ в Комсомольске-на-Амуре.
- Сохранены временная шкала, навигация, прогресс и мини-игры.
- Добавлена «Авиабитва» с Canvas, волнами, HP танков, очками и выбором изученных боевых самолётов.
